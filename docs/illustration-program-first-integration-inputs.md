# Illustration Program First Integration Inputs

## Zweck

Dieses Dokument enthält die **ersten drei direkt nutzbaren Inputs**
fuer ein externes Grafik- oder Illustrationsprogramm.

Diese Inputs bauen direkt auf:

- [illustration-program-input-structure.md](/Users/jonasweiss/MathTeach/docs/illustration-program-input-structure.md)
- [pilot-module-linear-equations-asset-mapping-sheet.md](/Users/jonasweiss/MathTeach/docs/pilot-module-linear-equations-asset-mapping-sheet.md)
- [epoch-antiquity-learning-content-priority-list.md](/Users/jonasweiss/MathTeach/docs/epoch-antiquity-learning-content-priority-list.md)
- [epoch-medieval-learning-content-priority-list.md](/Users/jonasweiss/MathTeach/docs/epoch-medieval-learning-content-priority-list.md)

Sie sind so formuliert, dass sie **nicht** das mathematische Gehirn
ersetzen, sondern nur den grafischen Produktionsauftrag sauber
beschreiben.

## Einsatzregel

Diese Texte sind fuer Programme gedacht, die:

- SVG oder Vektorillustrationen erzeugen
- ruhige Base Surfaces oder Carrier produzieren
- Varianten fuer `standard`, `repeat` oder `example` liefern koennen

Sie sind **nicht** dafuer gedacht, komplette UI-Screens mit Text,
Buttons oder fertigen Formeln zu generieren.

## Input 1: Linear Equations `relationship_intro`

```text
Project: MathTeach
Module: linear equations
Epoch: cross-epoch neutral learning carrier
Stage: relationship_intro
State Variant: intro
Output Type: primary carrier

Didactic Role:
Make a pre-symbolic relationship visible before equation notation so the learner first understands that two sides belong together.

Psychological Contract:
calm, dignified, low-pressure, non-testing, focused, safe, not childish, not gamified, quietly supportive

Primary Carrier Type:
Relationship Carrier

What Must Be Visible:
- one unknown whole as one calm distinct part on the left side
- exactly three identical added units on the same left side
- exactly seven identical total units on the right side
- a clear sense that both sides belong together as one relationship
- structural balance without a flashy balance-scale gimmick

What Must Stay Empty:
- quiet top safe zone for MathTeach title and short tutor line
- quiet mid or lower safe zone for later equation overlay
- one small explanation-safe zone
- breathing room near the future action area

Epoch Inflection:
Keep this carrier historically neutral and pedagogically direct. This is a learning carrier, not a historical scene.

Forbidden Distortions:
- no dashboard layout
- no floating cards
- no smartphone app styling
- no embedded equation text
- no cartoon mascots
- no classroom scene
- no decorative objects
- no second main idea
- no glossy 3D icon look
- no puzzle-box mystery gimmick for the unknown whole

Output Constraints:
- readable at 800x480 landscape
- one primary carrier only
- text and formulas will be added later by MathTeach
- vector-first preferred
- prepare one standard carrier and one repeat variant with reduced visual complexity

Deliverable:
- one SVG primary carrier for relationship_intro
- one simplified SVG repeat variant
- transparent or softly bounded background version if possible
```

### Produktionshinweis

Der wichtigste Punkt hier ist:

- nicht die Gleichung illustrieren
- sondern die **Beziehungslogik vor der Gleichung**

## Input 2: Antiquity `Pythagorean Relationship`

```text
Project: MathTeach
Module: pythagorean relationship
Epoch: Antiquity
Stage: relationship_intro
State Variant: standard
Output Type: primary carrier

Didactic Role:
Make the relation between the square on the shorter sides and the square on the longer side visible before the symbolic theorem statement dominates.

Psychological Contract:
calm, dignified, low-pressure, non-testing, focused, safe, serious without threat, not childish, not gamified

Primary Carrier Type:
Relationship Carrier

What Must Be Visible:
- one clear right triangle as the main geometric anchor
- one square on each of the two shorter sides
- one square on the longest side
- a visible structural belonging between the two smaller square areas and the larger square area
- geometric clarity before algebraic notation

What Must Stay Empty:
- quiet top safe zone for title and short tutor line
- one explanation-safe zone near but outside the main figure
- one formula-safe zone for later symbolic theorem overlay
- breathing room around the main geometric carrier so the figure is not cramped

Epoch Inflection:
Show form, relation, and ordered geometric thinking. Avoid antiquity as decorative setting. The image should feel like mathematics of form and proof order, not like an ancient museum postcard.

Forbidden Distortions:
- no temple scene
- no philosopher portrait
- no marble or papyrus decoration without teaching function
- no dense symbolic theorem wall
- no modern classroom board
- no dashboard layout
- no floating cards
- no ornamental frame overpowering the figure
- no second main idea

Output Constraints:
- readable at 800x480 landscape
- one primary geometric carrier only
- vector-first strongly preferred
- text and formulas will be added later by MathTeach
- prepare one standard version and one repeat version with fewer marked relations

Deliverable:
- one SVG primary carrier for the pythagorean relationship
- one reduced-complexity SVG repeat variant
- optional one sidecar-compatible variant with more breathing room for proof-step overlays
```

### Produktionshinweis

Der wichtigste Punkt hier ist:

- zuerst **Formbeziehung**
- erst danach spaeter Formel und Beweisordnung

## Input 3: Medieval `Place Value and Zero`

```text
Project: MathTeach
Module: place value and zero
Epoch: Medieval Transmission and Synthesis
Stage: place_value_intro
State Variant: standard
Output Type: primary carrier

Didactic Role:
Make positional value visible before formal rule compression so the learner sees that a numeral changes mathematical role through place and that zero stabilizes positional structure.

Psychological Contract:
calm, dignified, low-pressure, non-testing, focused, safe, not childish, not gamified, quietly procedural

Primary Carrier Type:
Quantity Carrier

What Must Be Visible:
- the same numeral shape appearing in different positional roles
- a clear positional structure that makes value depend on place
- one visible role for zero or empty-position logic as structural stabilizer
- a calm sense of ordered calculation rather than a wall of numerals

What Must Stay Empty:
- quiet top safe zone for title and short tutor line
- one explanation-safe zone beside or below the main positional carrier
- one notation-safe zone for later MathTeach overlays
- breathing room so the positional structure remains readable at a glance

Epoch Inflection:
Show procedure, place structure, and transmission logic. Do not turn the image into decorative manuscript nostalgia. The medieval inflection should feel like orderly written mathematics becoming more powerful and transferable.

Forbidden Distortions:
- no orientalist scenery
- no scholar portrait
- no market or palace scene
- no decorative manuscript wallpaper
- no dense number table without meaning
- no dashboard layout
- no floating cards
- no smartphone app styling
- no second main idea

Output Constraints:
- readable at 800x480 landscape
- one primary carrier only
- vector-first preferred
- text and numerals for final explanation will be added later by MathTeach where possible
- prepare one standard version and one repeat version with reduced positional complexity

Deliverable:
- one SVG primary carrier for place value and zero
- one simplified SVG repeat variant
- optional one transparent-background version for integration into different base surfaces
```

### Produktionshinweis

Der wichtigste Punkt hier ist:

- nicht eine “historische Rechentafel” bauen
- sondern **Position als Bedeutung** sichtbar machen

## Integrationsreihenfolge

Wenn du diese drei Inputs in ein Grafikprogramm gibst, ist die
empfohlene Reihenfolge:

1. `linear equations - relationship_intro`
2. `Antiquity - pythagorean relationship`
3. `Medieval - place value and zero`

## Warum genau diese Reihenfolge

- Input 1 prueft den neutralen Device-Lerncarrier
- Input 2 prueft die erste echte Epochen-Uebersetzung in Geometrie
- Input 3 prueft die mittelalterliche Verfahrens- und
  Stellenwertlogik

Damit decken die drei ersten Integrationen bereits ab:

- neutraler Modulcarrier
- antike Formbeziehung
- mittelalterliche Positions- und Rechenordnung

## Praktische Arbeitsregel fuer externe Tools

Wenn ein Tool zu viel Text, UI oder Dekoration erzeugt, dann nicht den
gesamten Input umwerfen.

Zuerst nur diese Felder nachschaerfen:

1. `Forbidden Distortions`
2. `What Must Stay Empty`
3. `Primary Carrier Type`
4. `Didactic Role`

Denn genau dort kippt ein ansonsten brauchbarer Input sonst wieder in
generischen Illustrationsmuell.
