## Locked Instruction Block

Diesen Block immer voranstellen:

```text
Create a mathematically functional visual explanation for the Medieval Transmission and Synthesis epoch in MathTeach.
The image must teach one single mathematical idea.
The scene must feel calm, procedural, dignified, and non-testing.
Use position, operation, transmission, or evolving notation before dense modern symbolic compression.
Avoid exotic staging and avoid decorative medieval imagery.
The composition must work on an 800x480 landscape learning device with one primary carrier.
```

## Negative Block

```text
No orientalist scene, no scholar portrait as main image, no palace or bazaar staging, no decorative manuscript wallpaper, no museum display, no modern classroom board, no dashboard layout, no floating UI cards, no red error cues, no gamification, no second main idea, no dense symbolic wall, no ornamental calligraphy used as distraction.
```

## Prompt M1: Place Value and Zero

```text
Show a calm explanation of place value and zero in a medieval mathematical context.
Make positional meaning visible.
The learner should see that the same numeral changes role by place, and that zero or an empty place stabilizes structure.
Keep the carrier instructional, not antiquarian.
The image should feel like mathematical ordering, not like a decorative number table.
```

## Prompt M2: Brahmagupta Rule Carrier

```text
Show one medieval arithmetic rule as a controlled local operation.
The learner should see a before-state, a rule being applied, and an after-state.
Keep the number of visible cases small.
The carrier must make the rule feel understandable and repeatable, not magical.
Do not turn the image into a list of many cases or a symbolic wall.
```

## Prompt M3: Rhetorical Algebra

```text
Create a calm explanation carrier for early rhetorical algebra in the line of al-Khwarizmi.
Show a problem, a bounded procedure, and an emerging algebraic structure.
The learner should feel that algebra is becoming a language of ordered operations, not yet a compressed symbolic code.
Do not start with a modern finished equation as the main event.
```

## Prompt M4: Transmission and Commentary

```text
Create a quiet transmission carrier for medieval mathematics.
Show that mathematical knowledge moves through texts, commentary, and teaching stations.
Keep the chain small and readable.
The learner should feel continuity and transformation, not spectacle or cultural tourism.
This image must remain mathematically anchored, not biographical.
```

## Prompt M5: Series and Approximation Bridge

```text
Create an explanation carrier for a medieval series or approximation idea in the line of Madhava.
Show an ordered sequence or approximation that visibly approaches a mathematical target.
Do not jump to modern Taylor or integral notation.
The learner should feel that medieval mathematics is already generating future analysis through structured approximation.
```

## Prompt M6: Quiet Historical Sidecar

```text
Create a quiet historical sidecar for medieval mathematics.
The image must support dignity, continuity, and transmission without becoming a historical costume scene.
Show a light sense of textual or school-based continuity while keeping the main mathematical carrier central.
This sidecar must remain visually secondary.
```

## Optional Vector Add-On

```text
Prefer clear structural groupings, distinct layers, readable table or line relations, and carrier shapes that remain legible at 800x480.
```

## Optional Raster Add-On

```text
Use restrained texture and clear silhouettes so the explanation carrier stays readable and can later be simplified into a vector asset system.
```
