# Curation Loop

## Regel

MathTeach erweitert den historischen Mathematik-Korpus immer im gleichen Zyklus:

1. `audit`
2. `works`
3. `access`
4. `post-audit`

## 1. Audit

Vor jeder neuen Runde wird der aktuelle Bestand gegen kanonische oder wiederholt genannte Literatur verglichen.

Ziel:

- fehlende Schluesselwerke erkennen
- Epochenluecken erkennen
- Brueckenliteratur identifizieren

## 2. Works

Danach werden priorisierte Werke in die historischen und operativen Manifeste aufgenommen.

Dabei werden mindestens festgehalten:

- Werk
- Epoche
- Person oder Tradition
- mathematische Rolle
- historische Rolle

## 3. Access

Fuer jedes neue Werk werden danach Lesepfade und Speicherpfade dokumentiert.

Mindestens:

- heutiger Zugriffsweg
- Rechteklasse
- lokaler Ablagepfad

## 4. Post-Audit

Jede Ergaenzungsrunde endet mit einem neuen Audit.

Dieses Post-Audit fragt:

- Welche Luecken wurden geschlossen?
- Welche Brueckenwerke fehlen noch?
- Welche Epochen sind jetzt tragfaehiger?
- Was ist die naechste Prioritaetsrunde?

## Projektregel

`Kein Werk-Intake ohne anschliessendes Audit.`
