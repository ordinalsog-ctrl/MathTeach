# Library Storage

Dieses Verzeichnis ist fuer lokale Quellenablage vorgesehen.

Empfohlene Struktur:

- `raw/public_domain/<source-slug>/`
- `raw/restricted/<source-slug>/`
- `normalized/<source-slug>/`
- `cache/`

Wichtig:

- grosse Rohdateien bleiben ausserhalb von Git
- Metadaten und Manifeste bleiben im Repo
- Rechte und Provenienz muessen je Quelle dokumentiert werden
