## Locked Instruction Block

Diesen Block immer voranstellen:

```text
Create a mathematically functional visual explanation for the Early Modern Analysis and Chance epoch in MathTeach.
The image must teach one single mathematical idea.
The scene must feel calm, process-oriented, dignified, and non-testing.
Use change, approximation, local relation, or structured uncertainty before dense final notation.
Avoid scientist-myth staging and avoid decorative early-modern imagery.
The composition must work on an 800x480 landscape learning device with one primary carrier.
```

## Negative Block

```text
No Newton-vs-Leibniz portrait duel, no apple myth, no planet or telescope spectacle, no heroic laboratory scene, no casino or gambling table as main image, no modern classroom board, no dashboard layout, no floating UI cards, no red error cues, no gamification, no second main idea, no dense symbolic wall, no decorative scientific wallpaper.
```

## Prompt E1: Tangent and Change

```text
Show a calm visual explanation of local change and tangent thinking.
The learner should see a curve or changing relation and a local straight relation that makes the change readable.
The image must make the local nature of the tangent visible before formal derivative notation dominates.
Keep the carrier about relation and process, not about physical spectacle.
```

## Prompt E2: Area and Summation

```text
Create a calm explanation carrier for area as summation or approximation.
Show a region and a controlled buildup through smaller pieces.
The learner should feel that area is being approached step by step, not magically named by a final symbol.
Do not start with a finished integral expression as the main event.
```

## Prompt E3: Differential or Fluxion Notation

```text
Show the emergence of a new notation for change.
The carrier must connect an underlying process problem to a compact symbolic form.
The learner should see that the notation is useful because it organizes a new mathematical way of thinking.
Do not let the notation become a dense wall detached from the process.
```

## Prompt E4: Probability Structure

```text
Create a calm explanation carrier for early probability.
Show a small structured space of possible cases or outcomes that can be compared.
The learner should feel that chance is being organized into a readable mathematical structure.
Avoid gambling spectacle or theatrical uncertainty.
```

## Prompt E5: Logarithm or Series Bridge

```text
Show a mathematical bridge carrier for logarithms or early series reasoning.
The image must make visible that a new representation simplifies calculation or approximation.
The learner should feel that the tool changes what becomes manageable.
Avoid starting with a dense symbolic formula page.
```

## Prompt E6: Quiet Historical Sidecar

```text
Create a quiet historical sidecar for early modern mathematics.
The image must support dignity, transition, and mathematical productivity without becoming a myth scene.
Show a light sense of scientific and textual transition while keeping the main mathematical carrier central.
This sidecar must remain visually secondary.
```

## Optional Vector Add-On

```text
Prefer clear curves, local markers, structural groupings, and process layers that remain legible at 800x480.
```

## Optional Raster Add-On

```text
Use restrained texture and clear silhouettes so the explanation carrier stays readable and can later be simplified into a vector asset system.
```
