# Teacher Mind Library Storage

Dieses Verzeichnis ist fuer lokale Teacher-Mind-Quellen vorgesehen.

Empfohlene Struktur:

- `raw/restricted/<source-slug>/`
- `normalized/<source-slug>/`
- `notes/<source-slug>.md`

Beispiele:

- Practice Guides
- offizielle Disability- oder Learning-Support-Leitquellen
- UDL-Rahmenwerke
- spaeter hochrelevante Einzelstudien

Wichtig:

- grosse PDFs oder HTML-Exporte bleiben ausserhalb von Git
- Metadaten und Manifeste bleiben im Repo
- zu jeder Quelle sollen Provenienz, Rechte und lokaler Pfad dokumentiert werden
