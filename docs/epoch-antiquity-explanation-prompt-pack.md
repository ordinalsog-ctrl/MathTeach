## Locked Instruction Block

Diesen Block immer voranstellen:

```text
Create a mathematically functional visual explanation for the Antiquity epoch in MathTeach.
The image must teach one single mathematical idea.
The scene must feel calm, orderly, dignified, and non-testing.
Use form, relation, construction, or proof order before dense symbolic notation.
Avoid museum staging and avoid decorative antiquity imagery.
The composition must work on an 800x480 landscape learning device with one primary carrier.
```

## Negative Block

```text
No temple scene, no philosopher portrait as main image, no decorative columns, no museum display, no random scroll props, no modern classroom board, no dashboard layout, no floating UI cards, no red error cues, no gamification, no second main idea, no dense symbolic wall, no ornamental antiquity wallpaper.
```

## Prompt A1: Counting and Grouping

```text
Show an ancient-style mathematical grouping explanation.
Make number visible as arranged units or marks, not only as numerals.
The learner should see quantity as a structured group that can be compared, counted, or partitioned.
Keep the scene calm and didactic, not archaeological.
The visual carrier must feel like an explanation of quantity, not a historical prop display.
```

## Prompt A2: Pythagorean Relationship

```text
Show a geometric relationship for an early explanation of the Pythagorean theorem.
The visual carrier must make the square-on-sides relation visible before any formula statement.
Use a clear triangle and clearly related square areas.
The learner should first see that areas belong together in a structured way.
Do not start with a² + b² = c² as the main event.
```

## Prompt A3: Euclidean Proposition

```text
Create a calm proof carrier for a Euclidean proposition.
Show one figure, a small number of marked relations, and a clearly bounded proof step.
The image must support theorem-plus-figure thinking.
It should feel like ordered reasoning, not like a finished dense textbook page.
Keep the proof architecture visible: figure, marked relation, local inference.
```

## Prompt A4: Construction Step

```text
Show a geometric construction as an ordered step, not as a decorative tool scene.
One new line, circle, or segment should visibly emerge from the existing figure.
The learner should be able to tell what has just been added and why it matters.
Construction must feel procedural and clear, not artisanal or romantic.
```

## Prompt A5: Archimedean Approximation

```text
Create an explanation carrier for an Archimedean exhaustion idea.
Show a shape and a controlled approximation or subdivision inside or around it.
The image must make visible that we are approaching area or volume through ordered smaller parts.
Do not jump to modern integral notation.
The learner should feel: ancient mathematics is already reasoning carefully about near-completion and limit-like structure.
```

## Prompt A6: Quiet Historical Sidecar

```text
Create a quiet historical sidecar for Antiquity mathematics.
The image must support dignity and historical belonging, not person worship.
Show a light sense of transmission, commentary, or preserved mathematical structure without turning the image into a museum scene.
This sidecar must remain visually secondary to the main mathematical carrier.
```

